# SSH Диагностика сервера

Многофункциональный инструмент для диагностики и администрирования удалённых серверов через SSH с поддержкой панелей управления **FastPanel** и **ISPmanager**.

---

## 📋 Возможности

### 🔌 Подключение
- SSH-подключение по паролю или приватному ключу
- Автоматическое определение типа панели управления (FastPanel / ISPmanager)
- Интерактивный терминал с историей команд
- Переключение между серверами без перезапуска программы
- Кнопка "Подключиться" меняется на "Отключиться" (красная) после успешного подключения

### 📊 Диагностика
- **Полная диагностика** – все проверки в одном отчёте
- **Диски и память** – использование дискового пространства, inodes, оперативная память
- **Сеть** – интерфейсы, маршруты, внешний IP, интерфейс по умолчанию, привязка плавающего IP
- **Фаервол** – состояние ufw, iptables, nftables
- **Конфигурация веб-серверов** – проверка синтаксиса nginx и apache
- **Логи сайтов** – поиск ошибок в error-логах (поддержка FastPanel и ISPmanager)
- **Анализ логов доступа** – топ IP, URI, User-Agent с фильтром по дате (поддержка ротационных .gz)
- **Поиск OOM** – поиск событий Out-Of-Memory в системных логах (kern.log, syslog)

### 🌐 DNS
- **DNS-проверка** – A, NS, PTR записи (на сервере или локально)
- **DNS-резолверы** – просмотр текущих DNS-серверов и проверка доступности
- **Изменение DNS** – редактирование DNS-серверов через интерфейс (поддержка netplan, systemd-resolved, network-scripts)
- **Исправление dhclient DNS** – добавление supersede для предотвращения перезаписи DNS от DHCP

### 🔧 Администрирование
- **Редактор конфигов** – просмотр и редактирование конфигурационных файлов (nginx, apache, php, mysql) с созданием резервных копий
- **Замена IPv4** – замена IP-адреса во всех .conf-файлах в /etc
- **Замена IPv6** – замена IPv6-адреса во всех файлах в /etc
- **Перезапуск служб** – перезапуск nginx, mysql, apache

### 🎛️ Управление ISPmanager
- Перезапуск панели (`mgrctl -m ispmgr exit`)
- Принудительное завершение процесса core (`killall core`, `pkill -9 core`)
- Обновление панели (`pkgupgrade.sh coremanager`)
- Принудительный выпуск Let's Encrypt сертификатов (`letsencrypt.periodic`)
- Отключение панели (`chmod -x /usr/local/mgr5/bin/core && killall core && killall ihttpd`)
- Отключение модуля авторизации GeoIP (`usrparam setgeoip=off sok=ok`)
- Проверка и исправление переменной PATH в crontab (для корректной работы SSL)

### 💾 Управление Swap
- Создание swap-файла с указанием размера (проверка свободного места)
- Добавление swap в fstab для автоматического подключения

### ⌨️ Интерактивный терминал
- Ввод произвольных команд на сервере
- История команд (стрелки ↑↓)
- Команды `exit` или `quit` для отключения
- Кнопка "История" для просмотра последних 100 команд из ~/.bash_history

## 🚀 Установка

### Требования
- Python 3.6+
- pip
- Tkinter (обычно входит в состав Python)
- Для работы с Tkinter в Ubuntu: `sudo apt install python3-tk`

### Шаги установки

1. Клонируйте репозиторий:
git clone https://github.com/ваш-username/server-diagnostic-tool.git
cd server-diagnostic-tool

Создайте виртуальное окружение:
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# или venv\Scripts\activate  # Windows
Установите зависимости:

pip install -r requirements.txt
Запустите программу:

python3 main.py
📁 Структура проекта

server_diagnostic/
├── main.py # Точка входа
├── gui.py # Графический интерфейс (Tkinter)
├── diagnostic.py # Основная логика диагностики
├── ssh_client.py # SSH-подключение (Paramiko)
├── requirements.txt # Зависимости
└── README.md # Документация

### Описание файлов

| Файл | Описание |
|------|----------|
| main.py | Запускает GUI-приложение |
| gui.py | Весь графический интерфейс: окна, кнопки, поля ввода, терминал |
| diagnostic.py | Все функции диагностики: сбор метрик, анализ логов, DNS, замена IP, управление панелями |
| ssh_client.py | Класс для SSH-подключения через Paramiko |
| requirements.txt | Список зависимостей (paramiko) |

## 🎨 Интерфейс

Программа имеет тёмную тему в стиле GNOME и состоит из нескольких основных областей:

1. **Верхняя панель** – ввод данных для подключения (IP, порт, пользователь, пароль/ключ, тип панели)
2. **Кнопки диагностики** – все доступные проверки и действия
3. **Текстовое поле** – вывод результатов диагностики с прокруткой
4. **Интерактивный терминал** – ввод произвольных SSH-команд

### Кнопки управления

| Группа | Кнопки |
|--------|--------|
| Подключение | Подключиться / Отключиться |
| Диагностика | Полная диагностика, Диски и память, Сеть, Фаервол, Конфиги веб, Логи сайтов, Анализ логов доступа, Поиск OOM |
| DNS | DNS-проверка, DNS-резолверы, Изменить DNS, Исправить dhclient DNS |
| Администрирование | Заменить IPv4, Заменить IPv6, Перезапустить службы, Редактор конфигов |
| ISPmanager | Перезапустить панель, Kill core, Обновить панель, Выпуск SSL, Отключить панель, Отключить GeoIP, Проверить CRON, Исправить CRON |
| Swap | Создать swap файл, Прописать swap в fstab |
| Терминал | Send, История |

## 📝 Пример использования

1. Введите IP-адрес сервера, порт (по умолчанию 22), пользователя (по умолчанию root)
2. Введите пароль или укажите путь к приватному ключу (нажмите «Обзор»)
3. Выберите тип панели управления или оставьте «Авто»
4. Нажмите «Подключиться»
5. После успешного подключения:
   - Кнопка станет красной с текстом «Отключиться»
   - Все кнопки диагностики активируются
   - Появится панель управления ISPmanager (если определена)
6. Нажмите «Полная диагностика» для комплексной проверки
7. Используйте отдельные кнопки для детального анализа конкретных параметров
8. Для отправки произвольной команды используйте нижнее поле ввода
9. Для просмотра истории команд нажмите «История»

## 🔧 Поддерживаемые панели управления

### FastPanel
- Определение по наличию `/usr/local/fastpanel/bin/fastpanel`
- Поиск доменов в `/etc/nginx/fastpanel2-available/*/*.conf`
- Логи сайтов в `/var/www/пользователь/data/logs/*.log`
- Поддержка суффиксов `-frontend` и `-backend`

### ISPmanager
- Определение по наличию `/usr/local/mgr5/bin/mgrctl`
- Поиск доменов через `mgrctl -m webdomain list` или в `/etc/nginx/vhosts/*/*.conf`
- Логи сайтов в `/var/www/httpd-logs/domain.log`
- Полный набор кнопок управления панелью

### Без панели
- Определение доменов из стандартных конфигов nginx/apache
- Логи в `/var/log/nginx/`, `/var/log/apache2/`, `/var/log/httpd/`

## 🔒 Безопасность

- Пароли не сохраняются и не логируются
- Поддержка SSH-ключей для безопасной аутентификации
- Все операции выполняются через зашифрованное SSH-соединение
- Создание резервных копий перед изменением конфигурационных файлов:
  - Для конфигов: `файл.conf.bak.датавремя`
  - Для DNS: `/etc/resolv.conf.bak.датавремя`
  - Для crontab: `/tmp/crontab_backup.txt`
- Подтверждение всех критических операций перед выполнением

## 🛠️ Требования к серверу

### Базовые утилиты
- `df`, `free`, `uptime`, `ss` или `netstat`
- `ip`, `curl`/`wget`/`dig` (для определения внешнего IP)
- `systemctl` (для управления службами)
- `zgrep`, `zcat` (для работы со сжатыми логами)

### Веб-серверы
- `nginx` (для проверки конфигурации и перезапуска)
- `apache2` или `httpd` (для проверки конфигурации и перезапуска)
- `mysql` или `mariadb` (для перезапуска)

### Для ISPmanager
- `/usr/local/mgr5/bin/core` – основной процесс
- `/usr/local/mgr5/sbin/mgrctl` – управление панелью
- `/usr/local/mgr5/sbin/pkgupgrade.sh` – обновление панели
- `killall`, `pkill` – для управления процессами

---

## 🐛 Известные ограничения

- Для работы с ISPmanager необходимы права root
- Некоторые функции требуют наличия определённых утилит на сервере
- Анализ больших логов может занимать время
- Редактор конфигов не имеет синтаксической подсветки
- Автодополнение команд в терминале не реализовано (только история)

## 🔧 Устранение неполадок

### Ошибка `No module named 'tkinter'`

Установите Tkinter:
sudo apt install python3-tk  # Ubuntu/Debian
sudo yum install python3-tkinter  # CentOS/RHEL


### Ошибка подключения

1. Проверьте доступность сервера: `ping IP`
2. Проверьте SSH-порт: `telnet IP 22`
3. Убедитесь, что используете правильные учётные данные
4. Попробуйте подключиться вручную: `ssh user@IP`

### DNS не меняется

Проблема может быть в:
- **dhclient** – используйте кнопку «Исправить dhclient DNS»
- **netplan** – настройте через «Изменить DNS» (определяется автоматически)
- **systemd-resolved** – настройте через «Изменить DNS» (определяется автоматически)
