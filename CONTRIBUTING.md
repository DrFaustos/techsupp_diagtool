# Как внести вклад

Спасибо за желание улучшить инструмент!

## Настройка окружения

Создайте виртуальное окружение и установите зависимости:

- `python -m venv venv`
- `source venv/bin/activate`
- `pip install -r requirements.txt`

## Запуск инструмента

- `python main.py`

GUI на Tkinter (темы через ttkbootstrap).

## Тесты

- `python -m pytest tests/ -q`

Дымовые GUI-тесты без дисплея скипаются; в CI они идут под Xvfb
(см. `.github/workflows/tests.yml`).

## Процесс

1. Сделайте форк репозитория и создайте ветку от `main`.
2. Одна логическая правка — один PR.
3. Прогоните тесты локально; CI прогонит pytest на push/PR.
4. Оформите PR по шаблону: что изменилось и как проверено.

Для крупных изменений сначала создайте issue, чтобы обсудить подход.

## Стиль

- Соблюдайте существующий стиль кодовой базы (комментарии и докстринги на русском).
- Никогда не коммитьте адреса серверов, пароли и ключи.
